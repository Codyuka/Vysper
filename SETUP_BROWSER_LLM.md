# Настройка Browser LLM (DeepSeek, Qwen Chat и другие)

## 🌐 Поддерживаемые платформы

### 1. **HuggingChat** (Рекомендуется для старта)
- **URL:** https://huggingface.co/chat/
- **Логин:** Не требуется
- **Плюсы:** Мгновенный старт, бесплатно
- **Минусы:** Может быть медленнее платных аналогов

- **URL:** https://chat.deepseek.com/
- **Логин:** Требуется (бесплатно)
- **Плюсы:** Отличное качество ответов, быстрый
- **Минусы:** Нужна регистрация

### 3. **Qwen Chat** ⭐ (Отлично для RU/EN)
- **URL:** https://chat.qwen.ai/
- **Логин:** Требуется (бесплатно)
- **Плюсы:** Прекрасно понимает русский, технический контекст
- **Минусы:** Нужна регистрация

### 4. **Perplexity AI**
- **URL:** https://www.perplexity.ai/
- **Логин:** Требуется
- **Плюсы:** Поиск в интернете в реальном времени
- **Минусы:** Лимиты на бесплатном тарифе

### 5. **You.com**
- **URL:** https://you.com/
- **Логин:** Не требуется
- **Плюсы:** Поиск в интернете
- **Минусы:** Может требовать капчу

## 🔧 Первый запуск (Важно!)

### Для платформ с логином (DeepSeek, Qwen, Perplexity):

1. **Откройте настройки приложения** (`Cmd+,` или `Ctrl+,`)

2. **Временно отключите Headless Mode:**
   - Найдите переключатель "Headless Mode"
   - Выключите его (браузер будет видимым)

3. **Выберите платформу:**
   - DeepSeek Chat или Qwen Chat

4. **Сохраните настройки**

5. **Запустите любой запрос** (например, через голосовой ввод)
   - Откроется видимое окно браузера
   - **Войдите в аккаунт вручную** (если видите страницу логина)
   - Пройдите капчу если потребуется

6. **После успешного входа:**
   - Закройте браузер вручную (или подождите автоматического закрытия)
   - Вернитесь в настройки
   - **Включите Headless Mode обратно**
   - Сохраните

7. **Готово!** 
   - Куки сохранятся в профиле
   - Следующие запуски будут автоматически использовать вашу сессию
   - Браузер будет работать в фоне (невидимо)

---

## 🍪 Как работают куки

Приложение сохраняет профиль браузера в:
```
%APPDATA%/vysper/browser-profile/  (Windows)
~/Library/Application Support/vysper/browser-profile/  (macOS)
~/.config/vysper/browser-profile/  (Linux)
```

**Это означает:**
- ✅ Вам нужно войти только ОДИН раз
- ✅ Сессия сохраняется между перезапусками приложения
- ✅ Headless режим работает после первого видимого входа

## 🎯 Рекомендуемая конфигурация

Для собеседования на Python Backend Developer:

```
Local LLM: Qwen2.5-7B-Instruct (в LM Studio)
Big LLM Platform: DeepSeek Chat или Qwen Chat
Whisper Model: large-v3
Headless Mode: ON (после первого входа)
```

**Почему так:**
1. **Qwen2.5-7B** отлично обрабатывает смешанную речь (RU + EN термины)
2. **DeepSeek/Qwen** дают качественные технические ответы
3. **Whisper large-v3** максимально точно транскрибирует

## ❓ Troubleshooting

### "Таймаут ожидания начала ответа"
- Сайт мог заблокировать запрос или показать капчу
- **Решение:** Отключите Headless Mode, войдите вручную, включите обратно

### "Поле ввода не найдено"
- Структура сайта изменилась
- **Решение:** Обновите страницу в видимом режиме, проверьте что вы залогинены

### "Браузер не запускается"
- Возможно не установлен Chrome
- **Решение:** `npx puppeteer browsers install chrome`

### Сессия "слетела"
- Куки истекли или сайт потребовал повторный вход
- **Решение:** Повторите процедуру первого входа (см. выше)
